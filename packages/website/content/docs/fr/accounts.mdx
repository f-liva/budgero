Les comptes sont l'endroit où votre argent se trouve physiquement ; le budget est le plan que vous appliquez par-dessus. Budgero maintient cette distinction nette — c'est pourquoi choisir le bon type de compte a plus d'importance qu'il n'y paraît au premier abord.

Les comptes **dans le budget** alimentent votre budget : leur argent apparaît dans [À affecter](/docs/ready-to-assign) et leurs dépenses impactent les catégories. Les comptes **hors budget** (de suivi) contribuent au patrimoine net mais restent en dehors des calculs liés à la méthode des enveloppes — vous ne budgétez pas les fluctuations boursières de votre fonds de retraite.

Les cartes de crédit et les prêts sont **flexibles** : dans le budget si vous souhaitez que les mécanismes de gestion de dettes de Budgero s'occupent des paiements et du remboursement (voir [Suivi des dettes](/docs/debt-tracking)), hors budget si vous souhaitez uniquement suivre le solde.

## Soldes initiaux

Lorsque vous créez un compte avec un solde, Budgero l'enregistre comme une transaction d'ouverture afin que les comptes soient équilibrés dès le premier jour :

- Les **comptes d'actif** reçoivent une entrée (« Solde initial ») qui atterrit dans les revenus — ce qui signifie que votre argent existant devient immédiatement affectable.
- Les **comptes de dette** peuvent enregistrer à la fois le total emprunté et ce que vous avez déjà remboursé, de sorte que le solde reflète ce que vous devez réellement aujourd'hui.

## Comptes multidevise

Chaque compte peut être libellé dans plus de 120 devises fiduciaires ou 25 cryptomonnaies majeures, indépendamment de votre [devise du budget](/docs/budget-currency). Pour un compte en devise étrangère, chaque transaction stocke deux montants : le montant **original** (ce qui s'est réellement passé, dans la devise du compte) et la valeur **convertie** (ce que votre budget voit), ainsi que le taux de change utilisé.

Les taux sont résolus dans un ordre défini :

1. **Taux personnalisés** que vous avez fixés sur une période — utiles lorsque vous avez déplacé de l'argent à un taux connu.
2. **Taux récupérés** — Budgero récupère automatiquement les taux quotidiens.
3. **Taux manuels** que vous avez saisis — ils permettent également au multidevise de fonctionner entièrement hors ligne et sur des configurations auto-hébergées sans API de taux.
4. **Taux le plus proche** — le taux du jour antérieur le plus proche (jusqu'à une semaine en arrière) lorsque le jour exact n'est pas en cache.

Vous pouvez également remplacer le taux sur n'importe quelle transaction individuelle — l'outil idéal lorsque le taux de règlement réel de votre carte diffère de la moyenne du marché et que vous souhaitez que le montant converti corresponde à votre relevé au centime près.

## Rapprochement

Le rapprochement est l’habitude qui garde un budget fiable, que vous saisissiez vos transactions ou que vous les synchronisiez : vérifier que Budgero concorde avec votre banque.

Chaque transaction a un statut. Les nouvelles transactions saisies commencent **non pointées** ; touchez le **C** dans le registre quand elles apparaissent à la banque, et elles deviennent **pointées**. Les importations de fichiers bancaires arrivent déjà pointées, tout comme les transactions comptabilisées issues de la [synchronisation bancaire](/docs/bank-sync-enable-banking). L’en-tête du compte affiche votre solde **pointé** à côté du solde total : c’est le solde pointé que votre banque devrait afficher.

1. Ouvrez le compte et pointez les transactions déjà passées à la banque.
2. Cliquez sur **Rapprocher** et saisissez le solde affiché par votre banque. Budgero le compare au solde pointé.
3. S’ils diffèrent, trouvez l’écart : en général une transaction oubliée, un doublon ou une transaction pas encore pointée. Pour un petit écart, Budgero peut ajouter une transaction d’ajustement.
4. Confirmez : Budgero verrouille les transactions pointées jusqu’à aujourd’hui comme **rapprochées** et horodate le compte. Les transactions non pointées restent ouvertes pour la prochaine fois.

Les transactions rapprochées sont votre historique vérifié ; l’horodatage indique la fraîcheur de cette vérification. Un rapprochement hebdomadaire prend environ deux minutes par compte. Mensuel, ça marche aussi. « Jamais », c’est ainsi que meurent les budgets manuels : voir [À affecter](/docs/ready-to-assign) pour comprendre comment les écarts non rapprochés apparaissent dans vos chiffres.

## Fermer un compte

Les comptes sont **archivés**, pas supprimés. Un compte archivé disparaît des sélecteurs et des listes quotidiennes, mais toutes les transactions qu'il a jamais contenues restent dans vos rapports et votre historique — fermez votre ancien compte bancaire sans perdre cinq ans de relevés. L'archivage est réversible ; désarchivez-le et il revient exactement comme il était.

Avant l'archivage, ramenez le solde à zéro (transférez les fonds restants vers un autre compte) pour que votre patrimoine net et votre À affecter ne portent pas un solde fantôme.
